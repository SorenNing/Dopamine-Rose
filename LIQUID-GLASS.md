# Dopamine RootHide: five-theme native UI

The fifth selectable theme is **液态玻璃** (`liquid-glass`). It uses the pinned original Theseus material, tab bar/drag lens and switch; the old renderer has been removed. See [Theseus integration](Application/Dopamine/Theseus/INTEGRATION.md). The first four palettes remain unchanged and Glaze remains the default. The native harness now compiles the actual Swift and Metal sources and checks all five themes with 85 screenshots. Physical-device visual verification remains outstanding.

RootHide baseline: `3.x_roothide_AI_review_fix` (`3ac500e9d95553c2ffd651894315d79b31ee8aed`), version `3.0.13-30`, bundle `cn.zqbb.dopaRH`. Existing RootHide payloads and jailbreak implementation are retained.

Themes: 折纸 · 白昼 (`origami`), 琉光 · 青瓷 (`glaze`, default), 砂金 · 夜潮 (`nocturne`), 灰粉 · 玫瑰 (`dusty-rose`). All four share the same native UIKit layout. The restored Dusty Rose reuses its original background and primary/secondary/accent palette; Liquid Glass surface colors are new adaptations. Invalid theme preferences migrate to Glaze.

The static iOS launch storyboard uses a neutral fallback rather than the obsolete fixed pink. Once application code starts, the window and navigation surface use the currently selected theme. The system-rendered cold-launch screen cannot access app preferences, so it is not guaranteed to match every selected theme before app code runs.

The home page contains a centered brand surface, device-information card with the original issue notice, two restart cards, a fixed low jailbreak button and a three-entry glass capsule (Home, Settings, About). Settings, exploit/PAC/PPL/Jetsam/theme selection, credits/licenses, package-manager selection, logs/errors, update details and dormant download UI share the appearance system. System alerts, photo picker and share sheet use public style/tint properties.

On iOS 26 the surface factory resolves the public `UIGlassEffect` class and `effectWithStyle:` selector with availability checks. Older systems use public ultra-thin `UIBlurEffect` with theme tint, thin borders and shadows. Public blur styles do not reproduce CSS blur radius/saturation exactly. Reduce Transparency uses an opaque theme surface. No backboardd filter or private `CAFilter` is required.

Titan's two Xcode deployment targets are aligned to iOS 15, consistent with its declared iOS 16/17 support and the other bundled frameworks. Final archive validation inspects every embedded framework's actual Mach-O minimum OS; it rejects an accidental higher target rather than relying on source plist values.

UI corrections include per-instance preparation mutex initialization, real UIButton disabled state, main-thread workaround alert creation, per-controller fade state, Scene-aware windows/log sharing, navigation-owned full-size page roots with internal clipped surfaces, no private display-corner KVC, masked public log blur, initial incremental-log handling and download timer cleanup. Original RootHide gates/run/finalize/restart operations remain in the existing execution paths.

## Device-feedback layout correction

The 6553cc1 device videos exposed wrapping brand text, root-frame conflicts, rows escaping rounded surfaces, an overlapping second navigation bar, nested button backgrounds and dark switch thumbs. The correction uses one navigation-owned capsule and cached top-level stacks, UIKit standard page transitions, a shared explicitly single-line measured brand, and clipped inner page containers constrained above the capsule. Preferences tables are hosted inside those containers and use a single full-row background covering accessories. Action cells have transparent internal buttons. Boot-logo and section captions are localized. No jailbreak actions, defaults, authors, resource payloads or theme selection are removed.

The same manual workflow runs `.github/ui-tests/run.sh` before device compilation. It stages byte-identical production appearance, theme and navigation sources in a simulator harness and checks four themes at 320/390/430-point widths, brand compression, root bounds, clipped panel bounds, row/accessory coverage, navigation switching/push/pop and selection state. It saves native screenshots, assertion results and console logs, including sampled push/pop frames and transition-backdrop cleanup checks. Fixture controllers replace business actions and private Preferences, so this is shared-component UIKit verification, not a full on-device test; interactive swipe cancellation remains untested. The device archive is still verified separately.

Build manually: Actions → **Build Dopamine Rose RootHide** → Run workflow → `main`. The workflow has no push trigger. It builds the original complete RootHide project on macOS, produces byte-identical IPA/TIPA archives and verifies bundle/version, four required libraries, RootHide marker, UI selectors, compiled four-theme metadata and Mach-O signature load commands. `verify_liquid_glass.py` emits an artifact verification receipt. These checks do not establish on-device jailbreak success or visual equivalence; device testing remains separate.
